# 使用手册

## 从一篇论文开始

工作台「新建论文」只要求标题，其他信息可稍后填写。详情页「基本信息」支持论文中英文名称、作者、机构、年份、DOI、arXiv、链接、摘要、方向、关键词、日期、重要性和复现计划。阅读和复现状态互相独立。

上传 PDF 后点击「PDF 分栏」与笔记对照。内置 PDF.js 阅读器支持连续滚动、文字选取、搜索高亮、目录 / 缩略图导航和缩放，字体资源和 worker 均随应用存储在本地，不依赖浏览器 PDF 插件。可点击下载图标打开原文件；提供仅 PDF、仅笔记和分栏模式；保存页码、缩放及页内位置。选文可快速创建知识、插入笔记、保存高亮批注和精确出处，并生成 ChatGPT 提问；详见 [交互阅读指南](interactive_reading.md)。OCR 与区域截图暂未实现。图片上传后自动插入本地 Markdown 链接；其他附件作为列表保留。支持的类型和大小在界面提示，单文件最大 50 MB。

文献列表可切换卡片 / 表格视图，筛选状态、年份、方向、重要性、标签和全文；按标题、年份或更新时间排序。每页最多 100 条，使用分页继续。

## 写笔记和保存

知识笔记提供默认章节，都是普通 Markdown，可自由增加、删除、调整。正文支持标题、表格、任务清单、引用、Python 代码高亮、LaTeX 和 Mermaid。示例 JSON 中包含矩阵、分段函数、偏导、期望、求和、积分等公式，可用于检查排版。

编辑、预览、分栏模式在笔记上方切换；数学公式用 `$...$` 或 `$$...$$`。Mermaid 使用标注 mermaid 的代码围栏。内部链接格式：`[BPTT](#node/节点UUID)`，UUID 可从单条 JSON 导出获取。图片仅显示已上传的 `/api/attachments/UUID` 本地链接，外部图片被阻止，避免阅读笔记时发出追踪请求。

约每 1.4 秒自动保存一次，顶部有状态；Ctrl+S 手动保存。保存期间继续输入，会在下一次保存中提交后续内容。离开笔记前会尝试保存；若失败，将保留本地草稿并阻止应用内离开。关闭浏览器时会显示原生未保存提示。

遇到版本冲突（例如两个窗口编辑同一个条目）不会自动覆盖。请先下载草稿，再重新加载对比合并。本地草稿存在浏览器 localStorage 中，不等同于正式备份；浏览器清理数据会移除它。重新打开存在未保存草稿的条目时可选择恢复或舍弃。

修改历史保存正文和元数据，可展开任一旧版本，将其恢复为一个新版本；不会删除后续历史。科研想法的失败假设和原因建议放在笔记专门章节，即使状态变为已否定也会保留。

## 知识复用与关联

数学和算法尽量按主题创建独立条目。进入论文右侧「建立关联」，检索已有知识，选择方向与类型，添加说明和证据。对方详情页同时能看到该关联。related_to / compares_with 双向无方向；其他关系有方向，文字会注明本条目和对方。

数学、算法支持在基本信息中多选分类；设置中创建多级分类、修改名称或调整父分类。引用中的分类不能删除，避免资料失去分类。标签在详情标题下编辑，使用逗号分隔，删除标签文字即可移除。

重复的数学 / 算法等条目可以在详情右侧「合并重复知识」检索并选择同类目标，确认后当前条目进入回收站，目标笔记追加原文并保留旧文，关系复制到目标。词汇已有两个复习队列时暂不支持直接合并；建议使用结构化导入把新来源附加到同一个词汇。

## 科研英语与复习

词汇基本信息包含词性、词义标识、中文含义、科研语境、例句、翻译、搭配和来源。相同拼写的不同词义应使用不同 sense，必要时保留独立条目。

工作台或科研英语页面进入闪卡。先回忆，再显示答案，按 Again / Hard / Good / Easy 评分。支持来源论文、类别、标签、优先级、错词和到期筛选；列表每轮最多 100 条。已复习条目从本轮队列移除，Again 的词汇在约 10 分钟后再次到期，重新进入或刷新可开启下一轮。

算法 sm2-v1：初始 ease=2.5，最低 1.3；Again/Hard/Good/Easy 映射质量分 0/3/4/5。成功间隔为 1 天、6 天，此后为向上取整的前间隔×更新后的 ease；ease 调整为 `max(1.3, ease+0.1-(5-q)*(0.08+(5-q)*0.02))`。Again 清零连续成功，累计遗忘次数，10 分钟后到期。它是明确版本的 SM-2 变体，不声称等同 Anki 或 FSRS。完整评分、参数前后状态和时间永久保留，手动 mastery 与调度独立。

## 想法、问题与图谱

科研想法支持卡片、表格和按状态分列看板。在详情页修改状态后，条目移动到对应列；当前看板不支持拖拽跨列。记录假设、对比方法、实验设计、指标、风险和下一步行动，再关联论文 / 算法 / 数学。

问题支持类型、优先级、处理状态和解决过程。标记已解决后保留条目，解决时间自动填写，正文中的过程和结论不会被删掉。

知识图谱可按节点类别、关系类型和名称筛选，选择中心节点和 1–4 层深度；默认最近 100 节点，API 最大 250。拖动节点、滚轮缩放，双击打开详情。图谱布局只用于当前浏览，不持久化节点坐标。

## 搜索

Ctrl+K 打开全局搜索，搜索标题、作者、摘要、元数据、标签和 Markdown 正文，支持类别 / 标签 / 更新日期筛选。英文用 FTS5 加字面子串，中文用归一化子串回退，无需外部分词服务。最多显示 100 条；当前没有语义搜索、模糊拼写纠错或 PDF 原文内容索引。

## 导入、导出与备份

使用 [配套提示词](chatgpt_export_prompt.md) 要求 ChatGPT 按实际 Schema 导出，遵循 [导入格式](import_format.md) 的预览流程。软件不读取你的 ChatGPT 聊天记录，不把研究资料发给第三方。

单条详情「导出」提供 Markdown；「导入与导出」提供全库结构化 JSON、词汇 CSV 和完整 ZIP 备份。CSV 使用 UTF-8 BOM，防止以公式字符开头的字段在表格软件中作为公式运行。JSON 可供其他工具读取，完整恢复请使用 ZIP。

备份包括数据库快照、所有受管理正文历史、所有登记附件及非敏感配置和 SHA256 清单。默认 ZIP 保存在工作空间 backups 目录，并下载一份。通过 `RESEARCH_HUB_BACKUP_DIR` 设定服务端独立备份位置。不要只备份 SQLite 文件，活动数据库还可能存在 WAL；使用内置备份功能。

网页恢复仅允许新目录名称，创建当前工作空间同级新目录；不会替换当前资料。命令行 `scripts/workspace.py restore ... --target ...` 可选择任意不存在的独立目录，并支持网页上限以外的大备份（解压总量默认最多 2 GiB）。校验内容、路径、数据库、外键、附件和正文引用成功后才发布新目录。

恢复后停止服务，将 `--workspace` 指向新目录重启，核对论文数量、附件和关联后再继续。迁移到另一台 Windows / Linux 设备时同样使用 ZIP，不依赖机器绝对路径；experiment_path 等用户写入的外部实验目录需要人工调整。

## 删除、故障与升级

删除知识会先确认，再移入回收站；设置中可恢复。当前没有清空回收站或自动清理历史功能，优先避免误删。

磁盘满、权限不足、缺失 Markdown 会显示错误，不把缺失正文当空文本保存。先检查终端日志和剩余空间，再从备份副本恢复。进程中断后最多可能留下未引用的新 Markdown 文件；它们不会替代原指针，当前不自动清理。

升级前生成完整备份；替换代码、更新依赖、重新构建前端，再用原数据目录启动。Alembic 自动迁移，只运行到当前版本，不做破坏性降级。更换数据目录前停止服务，复制完整工作空间并保留旧目录作为回退。
