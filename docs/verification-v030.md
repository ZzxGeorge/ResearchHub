## 实际界面

隔离生产构建在内嵌浏览器测试了公共双栏三页 PDF（含文本、公式样例、向量框和图像扫描页）：

- 双击 posterior → 工具栏 → 科研英语，填入中文含义/词性保存；全局词汇数变为 1，当前论文自动出现知识与精确来源。
- 第二篇论文再次选同词，展示旧释义、来源、掌握和复习状态，选择追加语境后仍只有一个全局词汇。
- 点击论文原文标记进入知识详情，再点正文来源链接返回正确论文、附件和第 1 页。保留蓝色高亮及 LaTeX 批注。
- 150% 缩放和旋转操作后标记仍存在；适宽下实际截图确认 90 度旋转高亮对应 posterior。重新打开后原页/缩放/旋转与批注保留。
- 原文添加论文笔记，界面核对原有个人文字及新写的内容、原文、页码链接和解释同时保留；自动化另验证尚未保存的最新草稿不会被覆盖。
- 生成词汇解释提问并复制，读取实际剪贴板核对论文标题、文件页码、选词、上下文及对应指令。没有访问或发送 ChatGPT 对话。

第一轮界面发现扫描页事件不提供 numTextDivs，已改为检查实际 Text Layer 内容；最终构建需复验扫描页提示。部分大视口截图服务不可用，恢复默认视口后截图正常。
