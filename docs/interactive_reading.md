# 交互式论文阅读（v0.3.0）

在论文详情上传带文本层的 PDF，选择「PDF 分栏」或「仅 PDF」。选中词语或句子后，工具栏提供复制、高亮、科研英语、论文笔记和 ChatGPT 提问；「更多」中可创建数学、算法、想法和问题。

## 收集知识

快速录入面板复用全局知识库的元数据和正文模板，保存后无需离开论文。展开「原文与定位」可核对、清理选文并补充上下文、章节、印刷页码和来源说明。原始文本与清理后文本分别保留。已保存的原文证据保持原样；需要不同定位时重新选文。

同名词汇会显示已有释义、词义标识、来源、掌握程度和复习状态。可以追加语境、明确编辑原条目，或新建不同词义。追加保留原内容、优先级、掌握程度和全部 SM-2 历史；字段冲突会保留在补充正文中供核对。数学和算法也可搜索已有条目并追加应用实例。

没有中文含义和语境含义的词汇可以先收藏，不进入闪卡队列。在科研英语列表勾选「仅待完善释义」集中补充。填写任一有效释义后自动具备复习资格，已有复习状态不会重置。

正文的「内容来源」明确区分用户个人笔记、AI 辅助解释、论文原文摘录和外部参考资料。科研想法默认是个人笔记，不能视为论文作者结论。粘贴 ChatGPT 回答时选择 AI 来源，并自行核对。

## 笔记与来源

「添加笔记」可插入到编辑器最后光标位置或指定 Markdown 标题章节末尾，并附原文、文件页码和返回原文链接。插入使用编辑器的最新草稿，遵循原有自动保存和版本冲突检查。导出 Markdown 后，引文和页码仍可直接阅读；精确跳转需要 Research Hub 和对应工作空间。

知识详情的「原文出处」或正文中的来源链接会打开对应论文、选定 PDF 附件和页码，并临时突出原文约 8 秒。可通过「返回之前的知识条目」返回。缺失、回收站论文、文件哈希变化或超出页数的来源会明确报错，不应用旧坐标。

## 高亮与批注

高亮保存在工作空间，原始 PDF 不被修改。支持五种柔和预设颜色、自定义颜色与含义、Markdown / LaTeX 批注。页面左侧的小标记打开原文及相关知识；颜色覆盖层不截获正常选词。通过本篇面板的「编辑高亮 / 批注」修改或删除。批注正文以不可覆盖的 Markdown 修订文件存储。

同一处原文可以关联多个知识条目；一个知识条目可以有多篇论文的多个出处。高亮、来源和语义关系是独立数据：

| 操作 | 结果 |
| --- | --- |
| 删除批注 | 隐藏颜色和批注，保留原文定位、知识、复习历史和批注历史文件 |
| 解除此处来源 | 仅解除当前知识和这一处来源的联系，其他来源和语义关系保留 |
| 解除论文关联 | 解除此知识与当前论文的所有来源链接及语义关系，知识、批注和复习历史保留 |
| 删除定位 | 软删除这一处定位并隐藏其高亮，知识和复习历史保留；不物理清理文件 |
| 论文移入回收站 | 来源暂停显示和跳转；恢复论文后可再次使用，附件保留 |

「本篇知识收集」有笔记、批注、词汇、数学、算法、想法、问题标签，显示实际计数，可搜索、按页码/创建时间排序、定位、编辑、关联或解除。窄窗口中面板位于编辑器下方。

## ChatGPT 提问与总结导入

提问模式覆盖词汇、句子、数学、算法、科研思考和自定义问题。生成内容含论文标题、文件页码、选文和能确认的页面上下文，可预览、编辑并复制；软件不会读取 ChatGPT 对话、调用在线模型或自动发送消息。可用链接在系统浏览器打开官方 ChatGPT。

阅读完成后继续使用 `reading-summary-v1.schema.json`。导入预览会识别已手动收集的候选条目，由用户选择合并、新建或跳过。合并追加正文并保留手写内容、精确来源、批注和复习历史。v1 的 `metadata.sources` 是文字说明，不能携带或生成可靠的 PDF 坐标；不应让 AI 猜测本地附件 ID、哈希或坐标。精确定位通过本地阅读操作创建。

## 阅读状态与数据安全

PDF 页码、页内位置、缩放和旋转独立保存；论文阅读模式、分栏比例、面板标签、所选原文和快速录入草稿保存于工作空间。收起快速录入面板会保留草稿，重新打开论文可恢复。切换前会尝试保存；服务不可用时保留本机缓存并阻止离开。桌面缓存按工作空间隔离，不受随机本机端口变化影响。

完整 ZIP 备份包含数据库、全部知识和批注 Markdown 修订、PDF 附件、来源、多对多链接、批注与阅读状态。新增迁移前自动备份；恢复只写入不存在的新目录。请在关闭软件前留意保存错误。浏览器/桌面缓存尚未写入工作空间的极短时间内，另一个进程创建的备份不包含这些待提交内容。

## 边界

文本层决定可选择的内容和阅读顺序。清理断行连字符是启发式处理；原文可核对，双栏跨列选择不能保证语义顺序。公式乱码、扫描件、加密/损坏 PDF 或异常字体可能无法可靠选词；没有 OCR。未自动推断章节、印刷页码或不可确认的上下文。超大论文和所有真实排版尚未穷举。
