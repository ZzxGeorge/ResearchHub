## 已知限制 / 未验证

1. 没有干净 Windows 虚拟机；本机是安装了开发工具的 Windows 11。清理 PATH 的后端验证不等同于整套应用已在未安装 Python / Node 的 Windows 10/11 电脑通过认证。
2. 本次原生窗口自动化返回的截图与控件几何不稳定，因此仅确认了安装后的真实窗口 / 工作台启动；原生桌面窗口内 PDF 的全部交互、窗口缩放 / 多显示器、所有快捷键、目录切换、下载、权限策略还需要更完整的人工或 CI 验收。PDF 交互结果来自隔离内嵌浏览器，不冒充全部 Electron 集成验收。
3. 在本 Codex 源码目录直接运行 win-unpacked 触发了 Electron AppContainer ACL 拒绝并产生 0x80000003；安装到普通当前用户 Programs 目录后成功启动。没有修改 ACL、关闭沙盒或关闭 webSecurity。其他受限自定义安装目录未验证；请通过安装包使用。
4. 未做 Authenticode 数字签名，可能出现 SmartScreen / 未知发布者提示。未测试系统提示的用户放行流程。
5. PDF 文本选择与检索只适用于带文字层文档；OCR、摘录创建知识、持久批注 / 颜色高亮、批注列表不在本轮完成范围。搜索高亮是临时显示，不是写入标注。
6. 复杂 / 加密 / 超大 PDF、长论文资源占用、数学字体和所有双栏论文并未穷举。测试包含双栏文本、向量与栅格内容及无文字图像页；不是所有真实论文排版的保证。
7. PDF 目录依赖文件自带 outline；无目录时显示空提示。窗口内全屏回退不是操作系统级独占全屏。
8. UI 缓存位于 Electron userData，正式笔记在工作空间；完整知识库备份不含未提交的桌面草稿。重要草稿应先保存正文或下载。跨机器转移主题 / 浏览器草稿需另行处理。
9. 日志尚无轮转策略；大规模性能、崩溃 / 真断电、安装器跨大版本升级、失败迁移恢复向导尚需强化。备份恢复继续使用已有界面和 CLI。
10. v0.1.0 原有的搜索 / 导入合并 / 大备份上限等仍存在，详见历史状态；P3 高亮批注和摘录联动尚未实现。没有引入 AI、云同步或 Zotero。
